# 女朋友專屬一番賞 V4 正式版

Node.js + Express + PostgreSQL 的自選號碼一番賞網站。

## 正式版功能

- 玩家註冊、登入及共享好寶寶印章
- 管理員建立、發布、下架一番賞
- A賞固定保留，其他獎項可自由新增或刪除
- 儲存活動時預先隨機洗牌，玩家自行選擇尚未抽出的號碼
- 已抽號碼永久標記，抽獎紀錄保存籤號、獎項、玩家、時間與彈數
- 開始下一彈時保留舊抽獎紀錄，重設獎品數量並重新洗牌
- 管理員查看本彈籤位、調整玩家印章、查看歷史紀錄
- 匯出完整 JSON 備份
- Cloudinary 圖片上傳
- 手機版介面與 A/B/C/未中獎效果

## Render 必要環境變數

- `DATABASE_URL`：PostgreSQL 連線字串
- `JWT_SECRET`：JWT 密鑰
- `ADMIN_USERNAME`：管理員帳號，預設建議 `admin`
- `ADMIN_PASSWORD`：管理員密碼
- `ALLOW_REGISTRATION`：是否開放註冊，填 `true` 或 `false`

上傳圖片時還需：

- `CLOUDINARY_CLOUD_NAME`
- `CLOUDINARY_API_KEY`
- `CLOUDINARY_API_SECRET`

## 部署

1. 將本專案全部檔案上傳或覆蓋到 GitHub repository 根目錄。
2. Commit changes。
3. Render 會自動偵測 GitHub 更新並重新部署。
4. Render 日誌出現 `Girlfriend Kuji V4 Formal running` 後即可使用。
5. 玩家網址為 Render 服務網址；管理員後台為服務網址加 `/admin`。

## 資料安全

升級啟動時只會建立缺少的資料表與欄位，不會主動清除原本玩家、印章或抽獎紀錄。正式使用前仍建議先在管理後台下載一次 JSON 備份。

已有歷史抽獎紀錄的一番賞，系統會禁止直接替換獎項，以避免舊紀錄因獎項被刪除而損壞；仍可修改標題、介紹、主圖、每抽印章與上下架狀態。


## V4.1.1 管理員刪除玩家帳號
- 管理員可在「玩家與好寶寶印章」中永久刪除測試玩家帳號。
- 會清除該玩家的抽獎、獎品兌換與印章異動紀錄。
- 若玩家在目前這一彈抽過籤，會把該籤恢復為可抽並補回獎品剩餘數量。
- 管理員帳號不能透過此功能刪除。


## V4.2 真實撕票／咪牌模式
- 玩家確認抽獎後，後端會先鎖定該張票的獎項，再進入撕票畫面，因此停在咪牌階段不會改變結果。
- 支援手機觸控與桌面滑鼠。
- 可以從票券左側往右撕，也可以從右側往左撕。
- 撕到一半可以停下來，只露出部分獎項內容，模擬現實中的「咪牌」。
- 票面加入紙張紋理、撕裂纖維邊緣、掀起紙片、陰影與輕微震動回饋。
- 完全撕開後才會進入原本的 A/B/C/未中獎結果特效。
- 如果抽獎結果已經送回瀏覽器但意外重新整理，同一個分頁會嘗試恢復尚未揭曉的撕票畫面。


## V4.2.1 獎品區分組優化
- 玩家「我的獎品」會把同一彈、同一獎項、同一名稱且狀態相同的獎品合併顯示。
- 相同獎品以 ×N 大徽章顯示數量，並集中列出抽獎券號碼。
- 待兌換與已兌換仍分開，不會混在一起。
- 只調整顯示方式，不修改既有抽獎、兌換或 Neon 資料。


## V4.2.2 管理員獎品區分類
- 後台獎品兌換先依玩家分類，再依同一彈＋同一獎項＋同一獎品名稱分類。
- 每個類別會顯示總件數、待兌換數與已兌換數。
- 每一件實際抽中的獎品仍獨立保留，會顯示抽獎券號碼與完整抽中日期時間。
- 已兌換品項仍保留兌換日期，待兌換品項仍可逐件確認兌換。


## V4.2.3 搜尋與兌換分類優化
- 管理員獎品區改成：玩家 → 獎項（B/C/D...）→ 獎品名稱 → 每一筆抽中紀錄。
- B/C/D 等獎項區塊可收合/展開；每筆仍保留票號、抽中日期、兌換日期與獨立兌換按鈕。
- 管理員兌換區新增搜尋，可查玩家、獎項、獎品、票號、日期，並可篩選待兌換/已兌換。
- 玩家『我的獎品』新增搜尋，可查獎項、獎品名稱、票號。
- 玩家抽獎選票新增籤號搜尋；管理員籤位檢視也新增搜尋。
- 玩家抽獎紀錄另新增搜尋，方便查歷史獎項與票號。
- 本版僅前端整理/搜尋，不變更 Neon 資料表。
